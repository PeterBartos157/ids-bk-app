# IDS BK Clone (Quasar + Vue)

## Overview
This project is a mobile-first clone of the IDS BK application built with Vue 3 and Quasar Framework.

## Features
- Credit top-up simulation
- Single ticket purchase flow
- Active ticket countdown
- QR code ticket screen
- Connection search screen
- Stops screen
- Lines screen
- More menu screen
- Session persistence for credit and ticket state
- Mobile-friendly UI inspired by IDS BK

## Tech Stack
- Vue 3
- Quasar Framework
- TypeScript
- Vue Router
- QRCode

## Installation

```bash
npm install
```

## Development

```bash
quasar dev
```

## Run as PWA

```bash
quasar dev -m pwa
```

## Production Build

```bash
quasar build
```

### Production PWA Build
